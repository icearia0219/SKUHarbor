# 数据与来源能力

| 来源                  | P0 实际入口                                                                                                                              | 当前真实状态                                                                                                                                                               |
| --------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 本品资料/规格         | `ingest.ts:importAssets`、`facts.ts:stageFactCandidates/confirmFacts`，授权 CSV/JSON/文本/DOCX/PDF                                       | 无用户真实商品；合成 US/DE 独立 SKU 已验证。PDF 依赖本机缺少的 pdftotext，实际二进制未验                                                                                   |
| 平台规则/PTD/品牌资料 | 先 SourceAsset，再 `knowledge.ts:ingestKnowledge` 审核与范围/版本过滤                                                                    | 当前为 synthetic 示例；标准/部分字段检查不能冒充 Amazon 扩展词汇/卖家条件全量审核                                                                                          |
| SP 搜索词/活动报表    | `reports.ts:parseAdReport`，两种确定模板 CSV/XLSX 与显式 mapping/metadata                                                                | 合成模板经工程验证；无脱敏真实报表，来源为 import 非 live                                                                                                                  |
| 客服工单              | task support 的有界工单文本；`prepareSupportContext` 脱敏                                                                                | 无真实工单；只送必要上下文，完整 ticket chunk 不进模型证据                                                                                                                 |
| 已审核订单导入        | `tasks/order-context.ts:approvedOrderContext` + `service.ts:freezeTask`，request.asset_ids 显式选择的唯一适用且同 SKU 的已审核 JSON 来源 | 人工核验导入，不是 SP-API 回执。原 verified/evidence ID 不可信；完成需真实存在的 receipt ID/时间，内部 hash ID，模型 ticket ID 为内部 hash，仅见必要字段证据；真实业务未验 |
| 竞品/评论资料         | 授权 SourceAsset，research 只读候选证据                                                                                                  | synthetic 候选；不为本品事实/认证背书，不推销量/利润                                                                                                                       |
| SP-API / Ads API      | P1，只读连接后续                                                                                                                         | 未接入，不计为在线成功；未安装平台写工具                                                                                                                                   |
| ESCI / Reviews2023    | 可选研究，不捆绑                                                                                                                         | 未下载，不宣称相关性或德语语言成绩                                                                                                                                         |
| benchmark/demo        | `benchmarks/ecommerce-ops/inputs/`、`docs/ecommerce-ops/templates/` 与自建临时数据                                                       | controlled fixture，provenance=synthetic、human_review=not_reviewed；120 案来自 30 个家族，封存 60 案来自 15 家族；家族内相关，分区不等于真实独立业务案例                  |

导入保存 workspace/owner_scope、来源权属 rights_note、provenance、market/locale/product_refs、observed/effective/known 时间、版本及 SHA-256。知识范围与产品绑定不能通过清空 product_refs 扩大；人工审核不允许回填 known 时间改变历史回放。过期、未知适用性、未审核或错站点规则不作生效依据。

原文是数据，不是系统指令。SourceAsset 原文与完整订单/工单仍通过授权 BLOB 留存；模型只收最小必要内容，客服先脱敏，订单证据为定位到 JSON 字段的时间/状态片段。模型由既有 Provider 配置决定，必要证据会发给该外部提供方；自托管不等于本地推理。API keys、Cookie、真实 Endpoint 与 PII 不得进入评测/Git 日志。

无可靠价目时成本为 unknown，不能填零。真实模型开发样本与 v1.1 封存第一轮 A/B 均有脱敏证据：原 A22/60、B16/60；同产物 scorer-v2 复评 A27/60、B17/60，新增模型调用 0；未达标。产品守卫修正第二轮已完成：A25/60、B21/60，两组评分未达标、共108次模型响应；包含产品代码变更与随机模型重新输出，不能与评分修正或纯方法提升混报；真人试运行仍为 0。来源、模型、语言与业务验收状态详见 [acceptance.md](acceptance.md)。
