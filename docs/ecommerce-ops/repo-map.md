## 实际 API

所有业务路径均在 `/api/ecommerce-ops` 下并使用登录会话与 workspace 授权：

- GET `availability`、`health`、`workspace`、`tasks/:id`、`artifacts/:id`、`assets/:id/content`、`evidence/:id`。
- POST `products`、`assets`、`products/:id/confirm`、`knowledge`、`reports`、`tasks`、`tasks/:id/{resume,pause,cancel}`。
- PATCH `artifacts/:id`；POST `artifacts/:id/review`、`artifacts/:id/follow-up`、`follow-ups/:id/refresh`；GET `artifacts/:id/export`。

提交任务返回 202，人工等待不持续调用模型。没有上架、改价、广告修改、退款、发货或发送客服消息端点。平台 SP-API / Ads API 保持 P1 未接入。
